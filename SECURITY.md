# Security policy

## Supported releases

Security fixes are made against the latest XNote release. Older versions may
not receive backports.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository. Do
not open a public issue for a vulnerability that could expose note contents,
backup keys, recovery codes, credentials, or another user's system.

Include the affected version, operating system, reproduction steps, and the
security impact. Never attach real notes, keys, recovery codes, or credentials;
use disposable test data instead.

Ordinary bugs that do not have a security impact can be reported through the
[public issue tracker](https://github.com/spencercnorton/xnote/issues).
